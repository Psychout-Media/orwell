# A9 - Premiere entrances + the champagne toast (`ORWELL_PREMIERE_ENTRANCES`, default OFF)

PO (Ryne 2026-11-04, brief: orwell-playtest/bdd-audit/design/premiere-entrances-and-toast-brief.md). Coordinator rulings: ONE houseguest at a time (15 individual entrances, no groups); each entrance a SHORT vignette; the next arrival comes after 1-2 player messages of lull, or immediately on "next"/watching; NEVER gate on talking to them; the player's own toast speech is chat-authored, never forced. Old premiere (0111 champagne circle) stays BYTE-IDENTICAL when the flag is off (nothing new written to live state).

## Engine contract (H1)
- Flag: `const PREMIERE_ENTRANCES_ENABLED_DEFAULT = process.env.ORWELL_PREMIERE_ENTRANCES === "1"` (+ `setPremiereEntrancesEnabled`/`...Now`, add to flagDefaultParity NEVER_FLIPPED pin). Read at `createCharacter` (season start).
- Pure module `src/engine/premiereEntrances.ts`: `planEntrances(ids16, playerId, seed)` -> `{ order: id[16], playerPos: number /*0..15*/ }` (seeded Fisher-Yates on `hashSeed(seed+":premiere-entrances")`, a SIDE stream - never the season spine); `toastSpeakers(order)` -> `("host" | id)[]` (host first, then entrance order, the player's slot included as a marker the engine does NOT fill).
- `LiveSeasonState.premiereEntrance?: { order: id[]; playerPos: number; arrived: number /*count entered so far, incl. the player*/; stage: "entrances"|"toast"|"done"; spoke: string[] }` (optional, persisted, absent when off).
- Season start (flag on): set `premiereEntrance`; do NOT set `champagneCircle` yet. Those at order index < playerPos are "already inside" when the player walks in: record their arrivals at season start (each its own recorded event, witness = those already inside before them, NOT the player), mark them met (premiereMet/premiereHotReads/introducedNames). `arrived = playerPos`. Remaining arrivals are released by `advanceGame`.
- `advanceGame` (before the champagne branch): stage "entrances" -> release exactly ONE arrival per call: the NEXT in order; if it is the player's turn in the order, that call is the player's own entrance (every houseguest already inside meets the player: witness = inside + player). Record ONE event per arrival (`onPlayerEvent(content, witnessSet, "premiere-entrance")`, content = a public Vault-free line "<Name> arrives" - facts only); witness set = everyone already inside + the arriver (+ the player only if the player is already inside). Mark the arriver met/hot-read/introducedNames for the player when the player is a witness; fold a bounded FIRST READ into the relationship layer for each (witness -> arriver) pair via the existing consequence fold with public facets only (no new magnitudes: reuse the existing premiere-read fold; if none exists, a small bounded affinity/trust nudge from a seeded side stream). After the last arrival: `stage="toast"`, `champagneCircle="gathered"` (the existing whole-house pin). Return `advanceView(null)` plus an announcement/event `{beat:"premiere-entrance", detail:{arriver:{id,name}, index, of:16, insideNames:[...], playerEntrance:bool}}` (public names only).
- Stage "toast": each `advanceGame` releases the NEXT BATCH of up to 2 speakers (2: the narrator voices one-two a turn; a bigger batch left recorded speeches unvoiced in the live check) from `toastSpeakers` (host first). Record one `toast-speech` event per NPC speaker and one for the host (witness = whole house + player; content = "<Name> gives a toast" / "The host opens the toast"), skipping the player's slot (it is chat-authored and recorded by the normal scene belt). When none left: `stage="done"`, `champagneCircle="done"` (the existing release). Detail `{beat:"premiere-toast", detail:{speakers:[{id,name}|"host"], index, of}}`.
- While stage="entrances", whereabouts must show ONLY those inside (and the player pinned in the living room) - model it as a whole-house `houseEventInSession` kind `premiere-entrances` like `champagne-circle`, `present` = arrived. Un-arrived NPCs must not appear anywhere (whereabouts, rooms, presence ticks, society pairing, approaches, `socialInitiatives`).
- Board: `PremiereIntrosView.entrance?: { stage; index; total:16; playerPosition:number /*1-based*/; arrivedNames:string[]; justArrived?: {id,name}; speakers?: {id?:string,name:string}[] }` (public names only). `complete`/`powerReachable` semantics: NO "meet everyone" gate - keep them TRUE during the whole premiere exactly as the old circle does (the gate is gone, not re-added); the first HOH is still held by the FE message-count hold.
- Vault-free: public name/vocation/vibe facets only; add a live sentinel test (plant a hidden string in a character's Vault facet; assert it never appears in any entrance/toast event, board view, or announcement). Per-NPC knowledge: an NPC knows only what it witnessed (witness sets) - assert.
- Tests (tests/unit/premiereEntrances*.test.ts, roles only): order is a permutation of all 16; seeded (same seed same order; different seeds vary the player's position - assert >=3 distinct positions over 20 seeds); each houseguest enters exactly once (one event each); by the end of the toast every NPC and the player have met (witness-pairwise); host + every NPC speaker has a recorded toast-speech; the player's slot is not recorded by the engine; stages progress entrances->toast->done and only then does the old HOH-staging advance work; un-arrived NPCs absent from whereabouts; flag OFF -> snapshot byte-identical to a build without the feature and `premiereEntrance` absent; the entrance order draw does not perturb the season (twin test: same seed flag on vs off reaches the same Week-1 HOH comp result if the clock/ordering do not differ, or at minimum same `evictionOrder` of a full run with entrances auto-advanced); snapshot/restore mid-entrances resumes at the same arrival.

## Prompt + FE contract (H2)
- `momentPrompts.ts` premiere fragment: when `pr.entrance` is present, REPLACE the champagne-circle-introductions beat (1) with the ENTRANCES instructions and beat (2) with the TOAST instructions (staged by `entrance.stage`); when absent the existing text is byte-identical (golden-ish pin test). Entrance stage: voice ONE arrival per turn as a SHORT vignette (a line from the arriver in their own register + one observable vibe + one reaction from someone already inside), from the card of `entrance.justArrived`; never invent who is present (`arrivedNames` is the whole inside list); small-group chat is the player's/NPCs' ordinary talk; after the vignette call `advanceGame` ONLY when the player lulls (1-2 messages) or asks for the next / says they just watch. NEVER gate on talking to them, no roll-call recap. The player's own entrance (`playerEntrance`) is narrated from their POV: the room turns. Toast stage: HOST first in a generic production voice (no real/famous names), then each speaker a one-to-two sentence toast built from public facets (facts to voice, ADR 0003 - never a script), the player's slot invited as a chat turn ("your turn" - never forced, skip if ignored), then `advanceGame` per batch.
- FE pacing belt (`frontend/routes/chat_helpers.py` / agent loop): during `entrance.stage` in ("entrances","toast") the progression stall-nudge treats a lull of 1-2 player messages (or a readiness cue/"next"/"watch") as the cue to `advanceGame` (reuse the existing stall-nudge/forced-advance ladder; do not add a second mechanism). The premiere message-count hold (`_PREMIERE_SOCIAL_MESSAGES`, now 48 after #2079) starts counting only AFTER stage=="done". Flag off / no `entrance` on the board -> byte-identical behaviour. The FE reads ONLY `premiereIntros().entrance` / the board; it never infers the stage.
- FE tests (`frontend/tests/test_a9_*.py`): prompt switch on/off; nudge fires after the lull and not mid-exchange; hold counting starts after done; sentinel: no id/number strings in the fragment.

## As built + live findings (2026-11-04, after three live reruns on real DeepSeek)

Shipped DEFAULT ON (`ORWELL_PREMIERE_ENTRANCES`, #2086 / #2113; `=0` restores the old champagne circle byte-identically). Differences from the contract above, each driven by a live finding:

- **Toast batch is 2** (was 4): the narrator voices one or two speeches a turn; a bigger batch left recorded speeches unvoiced. The host is first. The toast is ~9 advances for 16 speakers + host, so the premiere is ~16 entrance turns + ~9 toast turns before the morning.
- **Voice-hold (#2123).** The engine records each batch, but a chatting player pulls the narrator off the circle. The pacing ladder holds the NEXT batch (max 2 consecutive turns) until this turn's narration voices every listed speaker.
- **No message-count hold once the toast is done.** The entrances + toast ARE the premiere; stacking the 48-message premiere hold on top froze the engine at `phase=premiere` for 25+ messages. The stall-nudge brings the day-break immediately and the ENGINE CLOCK then owns the 48-message morning (5 in-game min/message).
- **The schedule owns the hold once the clock is live** (`daySchedule` on the board): not due => hold; DUE => release at once (a hang-out that ran the clock to the HOH comp used to be frozen behind the count).
- **Anti-stale cap exemption.** The F1 anti-stale silent-advance cap held the nudge after two advances, so the engine stalled at an arrival while the narrator invented the rest; staged entrance/toast advances are exempt (`_premiere_staged`).
- **Prompt:** the narrator is told never to introduce an arrival the engine has not released, and to voice EVERY speaker listed this turn.
- **Witness grounding (A11, #2118).** A chat during the gathered toast now counts: `occupancy()` overlays the same whole-house gathered state `whereabouts()` shows.
- **Guard N-16** re-grounds a competition narrated as STARTED while the schedule says not due; **N-17** (#2115) replaces an invented first-person confession with a deflection when no engine disclosure lever ran that turn.
- **Test lanes.** The unit and BDD lanes pin the flag OFF per file (they test other features through the old premiere; entrance tests opt IN); property / UAT / calibration run the shipped default ON. juryReach + calibrationGradient held their bands ON. The reactive-twist secret-veto floor moved 12 -> 11 under ON (approved).

Known gaps: only `event-due` of the hang-out stops was seen on screen; the other four are unit-proven. The 300-seed PO-band gate with entrances ON was not run (juryReach + gradient is the bar the three-part-HOH flip used).
