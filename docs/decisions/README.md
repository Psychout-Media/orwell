| 0022 | [Authored cognition and narration voice ("fan out cognition, funnel narration")](./0022-authored-cognition-and-narration-voice.md) | **Accepted** (owner directive, 2026-07-21). Cognition never flows *through* the descriptor. **Arm C (#1739):** full-fidelity mode re-simulates the awake set live each turn — parallel cheap-tier + delta-fed prompts + budget guard degrading to salience-gated (feature 0131-S1), with a cost model + flagged A/B plan (feature 0132). **Arm D:** voice distinctiveness recovered content-neutrally (per-NPC fingerprints in the terminal block #1735, `voiceSignature` cues #1733) with a measurable attribution test. **Integrity invariants (testable):** cognition-only, bounded-input, knowledge-scoped (on ENGINE presence, ADR 0019/#1726), soul-anchored, funnel-narration, voice content-neutrality. **No closed-set authority moves to the model — but arms B/C/D each ship their OWN new gate** (per-call knowledge-scope, deterministic-under-fan-out, cognition-cannot-cross-into-closed-set-authority); `expressiveNonCollapse` + the Vault-Wall sentinels remain the proof **only for what they cover** — open-set non-collapse on the *existing descriptor path* — and do **not** by themselves prove the new cognition/authority paths. Umbrella over ADR 0021 (voice; not superseded) + features 0131/0132 (the implementer specs / feature-issue split); refines ADRs 0003/0005/0019. |
