# Short lists across the whole product: inventory (ORW-511)

Product owner, 2026-11-15: worry about "the short list problem across the whole product". Rule: nothing is dealt from a teeny list; everything is as close to unbounded as the offline floor allows, and the live writer authors from the game's own facts.

Scanned-site tables are generated by `ci/short_list_inventory.py` from `ci/short_list_scan.py` (the scanner the CI guard `ci/check_short_lists.py` runs) over src/ TypeScript, frontend Python and frontend/static/js. Comments and docstrings are not scanned: only string literals a model or a player can receive. Numbers only; no play text. Class 1 = a string list under 40 items feeding a random, hash or modulo pick. Class 2 = "e.g./for example/such as" inside a string, or a closed menu. Each marker counts once. The roughly 435 raw "e.g." hits on the card are almost all code comments.

## The guard

Every ORW-511 allowlist entry must carry its own reviewed reason (one per site for text, a written decision for each list); the guard fails on an ORW-511 entry without them.

`ci/check_short_lists.py` (scanner `ci/short_list_scan.py`, allowlist `ci/short_list_allowlist.json`) runs in `npm run ci:fast` and its test `frontend/tests/test_short_list_guard.py` plants a short list, an inline pick, a modulo index, an example line and a closed menu in TypeScript, Python and front-end JS and requires a failure for each. An allowlist entry carries a path, kind, name, ceiling, owner and reason; a new site in an already listed file exceeds the ceiling and fails. Each owner deletes or lowers its entries in its own PR. The threshold (40) and the deal-call patterns match the ORW-508 TypeScript guard; when that branch lands its `poolGuard508.test.ts` and allowlist can be folded into this single allowlist.

Known limits: a list built by a comprehension or `flatMap` from components is not flagged (that is how a composed floor is written); object tables and lists in other languages (shell, YAML) are not scanned; a prompt written without the marker words slips through.
