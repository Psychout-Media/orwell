## The guard

`ci/check_short_lists.py` (scanner `ci/short_list_scan.py`, allowlist `ci/short_list_allowlist.json`) runs in `npm run ci:fast` and its test `frontend/tests/test_short_list_guard.py` plants a short list, an inline pick, a modulo index, an example line and a closed menu in TypeScript, Python and front-end JS and requires a failure for each. An allowlist entry carries a path, kind, name, ceiling, owner and reason; a new site in an already listed file exceeds the ceiling and fails. Each owner deletes or lowers its entries in its own PR. The threshold (40) and the deal-call patterns match the ORW-508 TypeScript guard; when that branch lands its `poolGuard508.test.ts` and allowlist can be folded into this single allowlist.

Known limits: a list built by a comprehension or `flatMap` from components is not flagged (that is how a composed floor is written); object tables and lists in other languages (shell, YAML) are not scanned; a prompt written without the marker words slips through.
