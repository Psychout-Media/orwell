## Behaviour flags read raw by the engine (not on `/health`)

| Env var | Kind | Default | Deploy writes | Pinned opt-in (never flipped) | Note |
|---|---|---|---|---|---|
| `ORWELL_COMP_THEMES` | toggle | ON | - | - | themed competition variety; =0 turns it off |
| `ORWELL_DISABLE_DIVERSITY` | seam | off | - | - | TEST SEAM (#338 RNG-isolation golden test): =1 skips the diversity pass |
| `ORWELL_GEN_COMPETITIONS` | toggle | off | - | - | generative competitions (#1400); the God-Mode dial also sets it per sandbox |
| `ORWELL_HANGOUT_P_SCALE` | knob | 1 | - | - | live-verification knob (A15): scales the hang-out stop chances; the deploy never sets it |
| `ORWELL_MEMORY_CALLBACKS` | toggle | see memoryCallbackConstants | - | - | memory callbacks (narrator lines), read through MEMORY_CALLBACKS_ENV |
| `ORWELL_SAVE_FSYNC` | knob | background | - | - | ORW-404 kill switch: =sync restores the fully synchronous per-save fsync (default: the fsync runs off the request path); never changes the saved bytes, but =sync changes the durability guarantee (the default can lose the last saves on a host power loss; =sync is stronger, though the directory is still fsynced only at checkpoints, so a recent rename can be lost in either mode) |
| `ORWELL_WANT_MOVEMENT_K` | knob | 1 | - | - | calibration-measurement override of the want-movement strength; the deploy never sets it |
